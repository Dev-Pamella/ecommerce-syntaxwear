# SyntaxWear - Tênis e Sneakers Online

![SyntaxWear Logo](./images/logo/logo.svg)

A **SyntaxWear** é uma interface de e-commerce moderna e elegante voltada para a venda de tênis e sneakers de alta performance e estilo urbano. O projeto foca em uma experiência de usuário fluida, com design responsivo e organização modular de estilos.

## 🚀 Tecnologias

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5**: Estrutura semântica para melhor acessibilidade e SEO.
- **CSS3**: Estilização avançada com o uso de variáveis, Flexbox e Grid Layout.
- **Design Responsivo**: Adaptado para diferentes tamanhos de tela (Mobile e Desktop).

## 📦 Estrutura do Projeto

A organização dos arquivos segue uma lógica modular para facilitar a manutenção:

```text
ecommerce-syntaxwear/
├── css/
│   ├── components/       # Estilos específicos de componentes (Header, Footer, Hero, etc.)
│   ├── base.css          # Estilos base de tags globais
│   ├── reset.css         # Reset de estilos padrão do navegador
│   └── variables.css     # Definição de cores e variáveis globais
├── images/
│   ├── banners/          # Banners promocionais e imagens hero
│   ├── icons/            # Ícones da interface (SVG)
│   ├── logo/             # Logo oficial da marca
│   └── products/         # Imagens dos produtos e categorias
└── index.html            # Estrutura principal da página
```

## ✨ Funcionalidades

- **Menu Responsivo**: Navegação adaptável com menu hambúrguer para dispositivos móveis.
- **Seção Hero**: Destaque principal com chamadas para ação (CTA) claras.
- **Categorias**: Filtro visual por estilo (Casual, Esporte, Moderno, Futurista).
- **Grade de Produtos**: Layout dinâmico exibindo os principais modelos da loja.
- **Newsletter e Social**: Rodapé completo com captura de e-mail e links para redes sociais.

## 💻 Como Visualizar

Para visualizar o projeto localmente, basta seguir os passos abaixo:

1. Clone este repositório:
   ```bash
   git clone https://github.com/Dev-Pamella/ecommerce-syntaxwear
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd ecommerce-syntaxwear
   ```
3. Abra o arquivo `index.html` em seu navegador de preferência.
